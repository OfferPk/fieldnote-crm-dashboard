# Fieldnote CRM Dashboard

## Simple English guide

### Open and add contacts
Open the live CRM link above in your web browser. To add a person by hand, select **＋ Add contact**, enter their name, fill in any other details you want, then select **Save contact**. Phone numbers are kept as typed, including a leading `+`, zeroes, spaces, or punctuation.

### Import a file or Google Sheet
To upload a contact file, select **Choose files** and choose a CSV or Excel file from your device. Excel workbooks use their first sheet. The app also accepts TSV and TXT files; it looks for familiar column names such as name, city, country, phone, status, notes, and follow-up.

For one Google Sheet, paste its link in the single-sheet box and select **Load sheet**. For several Sheets, paste one link on each line in **Bulk public Google Sheets**, then select **Load sheets**. Sheets must be public or published so the app can read them without signing in. Private Sheets and Google sign-in are not supported. If a normal share link does not load, try the Sheet’s published or CSV-export link. **Clear** beside either link box empties only that box; it does not delete contacts already added to the CRM.

### Find and choose contacts
Use **Search contacts** to look for a contact, and use the **City / location**, **Country**, or **Status** lists to narrow the displayed rows. Select **Phone numbers only** to show only contacts that have a phone number. **Reset filters** clears the search and filters.

### Download contacts or phone lists
Choose **Unique records** or **All records**, choose a format, then select **Download**. Unique records keeps one copy of a contact the app recognizes as a duplicate; All records keeps every row, including repeats. This choice does not delete anything from your saved contacts.

Available formats are **XLSX** (an Excel workbook), **TXT** (readable plain text), **CSV** (a comma-separated table), **TSV** (a tab-separated table), and **JSON** (a structured data file). To save just phone numbers, choose **Phone numbers only — TXT list** or **Phone numbers only — CSV list**. The phone-list download follows your active search and city, country, and status filters. Unique phone lists remove repeated phone values; All records keeps them.

### Back up and restore
Select **Export backup** to download a JSON backup of your contacts. Keep that file somewhere private: it contains personal contact data. To bring contacts back, select **Restore / merge** and choose a backup JSON file. Restore adds its contacts to the current list; it does not replace the contacts already there. A backup is a separate file, so save it somewhere safe if you may need it later.

### Where your contacts are stored
Contacts are saved in the current browser on the current device. They are not uploaded to an account and do not automatically sync to another browser or device. Browser storage is not an automatic backup and may be lost if browser data is cleared or the device is changed. Keep a private backup if you need to preserve or move your contacts. Public Sheets are read without private sign-in; do not expect the app to open private Sheets.

## Roman Urdu guide

### CRM kholna aur contact add karna
Upar diye gaye live CRM link ko apne web browser mein kholen. Kisi shakhs ka contact khud darj karne ke liye **＋ Add contact** chunen, naam likhen, baqi jo maloomat dena chahen bharen, phir **Save contact** chunen. Phone number jaisa likhen waisa hi rehta hai—shuru ka `+`, zero, spaces aur doosri nishaniyan bhi.

### File ya Google Sheet se contacts lana
Apne device se contact file lane ke liye **Choose files** chunen aur CSV ya Excel file select karen. Excel workbook mein pehli sheet parhi jati hai. App TSV aur TXT files bhi leta hai. Yeh name, city, country, phone, status, notes aur follow-up jaise aam column naam pehchanne ki koshish karta hai.

Ek Google Sheet lane ke liye us ka link single-sheet box mein paste karen aur **Load sheet** chunen. Kai Sheets ke liye **Bulk public Google Sheets** box mein har link alag line par paste karen, phir **Load sheets** chunen. Sheet public ya published honi chahiye taa-ke app bina sign-in ke use parh sake. Private Sheets aur Google sign-in ka support nahin hai. Agar mamooli share link load na ho to Sheet ka published ya CSV-export link azmaen. Kisi bhi link box ke paas **Clear** chunne se sirf us box ka link mitta hai; CRM mein pehle se aaye contacts nahin mitte.

### Contact dhoondhna aur list chhantna
Kisi contact ko dhoondhne ke liye **Search contacts** mein likhen. **City / location**, **Country** ya **Status** ki list se dikhaye gaye contacts ko chhant sakte hain. Sirf phone number wale contacts dekhne ke liye **Phone numbers only** chunen. **Reset filters** search aur filters hata deta hai.

### Contacts ya sirf phone numbers download karna
**Unique records** ya **All records** chunen, file ka format select karen, phir **Download** dabayen. Unique records mein app ke nazdeek duplicate contact ki sirf ek copy hoti hai. All records mein har row rehti hai, chahe koi row dobara aaye. Is se saved contacts delete nahin hote.

Formats ka matlab: **XLSX** Excel workbook hai; **TXT** seedha parhne wala text hai; **CSV** comma se alag ki hui table hai; **TSV** tab se alag ki hui table hai; aur **JSON** data file hai. Sirf phone numbers chahiye hon to **Phone numbers only — TXT list** ya **Phone numbers only — CSV list** chunen. Phone-list download par aap ki maujooda search aur city, country aur status filters lagu hote hain. Unique phone list mein aik jaisa phone number dobara nahin aata; All records mein aata hai.

### Backup banana aur contacts wapas lana
Contacts ki JSON backup file download karne ke liye **Export backup** chunen. Is file ko mehfooz aur private jagah rakhen, kyun ke is mein contacts ki zaati maloomat hoti hai. Contacts wapas lane ke liye **Restore / merge** chunen aur backup JSON file select karen. Restore backup ke contacts ko mojooda list mein jorta hai; purane contacts ki jagah nahin leta. Backup alag file hoti hai, is liye zaroorat parne par ise sambhal kar rakhen.

### Contacts kahan rehte hain
Contacts isi device ke isi browser mein save hote hain. Yeh kisi account par upload nahin hote aur doosre browser ya device par khud-ba-khud sync nahin hote. Browser ka data automatic backup nahin hota; browser data mitane ya device badalne se contacts kho sakte hain. Contacts bachane ya doosre device par le jane ke liye private backup rakhen. Public Sheets bina private sign-in ke parhi jati hain; app se private Sheet khulne ki tawaqqo na rakhen.
